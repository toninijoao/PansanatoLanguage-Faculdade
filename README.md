# Pansanato Language

Site de uma escola de idiomas com cursos de Inglês, Italiano e Francês. Projeto Prático da disciplina de Programação Web Front-end.

🔗 **Site publicado:** https://toninijoao.github.io/PansanatoLanguage-Faculdade/

## Descrição

O projeto tem duas partes:

1. **HTML e CSS:** página principal com apresentação da escola e dos cursos, e página de cadastro (matrícula) que direciona para o login.
2. **JavaScript:** painel administrativo (`admin.html`) para cadastrar, listar, pesquisar e excluir usuários, com os dados salvos no Local Storage do navegador.

## Funcionalidades

- Página principal com cabeçalho, menu de navegação, cards dos cursos e rodapé com link para o currículo.
- Página de matrícula com formulário de 6 campos que leva ao login.
- Painel admin com cadastro de usuários (nome e e-mail), exibindo a data de envio.
- Lista de usuários salva em uma única chave do Local Storage (`pansanatoUsuarios`), em formato JSON.
- Pesquisa por nome ou e-mail.
- Limpar campos do formulário.
- Excluir um item ou todos os itens (da lista e do Local Storage).
