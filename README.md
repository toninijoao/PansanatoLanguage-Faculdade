Pansanato Language

Projeto de uma escola de idiomas com cursos de Inglês, Italiano e Francês, desenvolvido como Projeto Prático da disciplina de Programação Web Front-end.

-> Tecnologias
HTML5
CSS3
JavaScript
Local Storage
DOM
Web Storage API
-> Funcionalidades
Cadastro de matrícula
Login de usuários
Painel administrativo
CRUD de usuários
Armazenamento de dados via Local Storage
Interface responsiva
-> Objetivo

Aplicar conceitos de desenvolvimento Front-end, manipulação do DOM, armazenamento local e criação de interfaces web interativas utilizando JavaScript puro.
